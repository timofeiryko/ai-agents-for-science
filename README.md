# ИИ-агенты для исследований

Материалы семинара Тимофея Рыко. Цель курса — собрать личную исследовательскую среду с ИИ-ассистентом и пройти в ней академический цикл от постановки задачи до статьи. Мы учимся выстраивать агентский цикл, хранить переносимый контекст и проверять утверждения независимо от модели.

## С чего начать

1. Прочитайте [контекст курса](COURSE.md): философия, верификация и агентский цикл.
2. Выберите тему из [финальных проектов](PROJECTS.md). Проект с коннектомом дрозофилы и Lean — личный исследовательский проект Тимофея, остальные пять тем предложены участникам.
3. Откройте репозиторий в своём агенте и попросите прочитать [AGENTS.md](AGENTS.md), COURSE.md и PROJECTS.md. Сформулируйте один проверяемый вопрос и первый воспроизводимый эксперимент.

Можно передать агенту такую задачу:

> Прочитай AGENTS.md, COURSE.md и PROJECTS.md. Помоги мне выбрать проект с учётом моих интересов. Для выбранного проекта отдели гипотезу от известных фактов, проверь доступность данных и предложи минимальный эксперимент с базовой моделью, метрикой и независимой проверкой. Не представляй запланированные результаты как уже полученные.

## Что здесь опубликовано

Чистовые материалы первых двух презентаций, контекст курса и только вошедшие в финальную вторую презентацию проекты. Постановки проектов — гипотезы и планы проверки, а не отчёт об успешных экспериментах. Дополнительные практические пояснения в COURSE.md и AGENTS.md раскрывают принципы курса.

В репозитории нет черновиков, истории переписки, промежуточных экспортов, скриншотов, логов, ключей API и датасетов. Данные нужно получать у первоисточников с соблюдением их условий. PDF второй презентации сохраняет визуальное представление слайдов; для поиска и работы агента используйте Markdown.

Контекст подготовлен 03.11.2026. Вводная презентация — финальная локальная версия от 13.10.2026. Презентация проектов — финальная версия от 27.10.2026, дополненная ссылкой на этот репозиторий.

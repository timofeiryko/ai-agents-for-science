## Слайд 4

Данные и схема эксперимента

ИИ-агенты для исследований

04

Источники данных

Hemibrain: связи нейронов PN и KC.

DoOR: ответы рецепторов на запахи.

Модель преобразует входные ответы

в активность клеток Кеньона (KC).

Контрольная модель

Перемешанный граф связей

с сохранением степени каждого

нейрона. Входные данные и правило

обучения одинаковы для всех графов.

Метрики: точность при 1, 2, 5, 10 примерах на запах

и перекрытие кодов при одинаковом числе активных клеток.

Допущения: синтетический шум в профилях DoOR и отображение ответов

рецепторов на входы проекционных нейронов (PN).

## Слайд 5

КОННЕКТОМ ДРОЗОФИЛЫ

Ассоциативная память: теорема для Lean

ИИ-агенты для исследований

05

N запахам соответствуют бинарные коды aᵢ с k активными клетками.

Пересечение кодов разных запахов не превышает r клеток.

Правило Хебба для меток yᵢ ∈ {−1, +1}:

w = Σᵢ yᵢaᵢ

Оценка, подлежащая формализации при k > (N − 1)r:

yᵢ ⟨w, aᵢ⟩ ≥ k − (N − 1)r > 0

При k > (N − 1)r знак ответа совпадает с меткой каждого записанного кода.

## Слайд 6

ML / БЕЛКОВАЯ ИНЖЕНЕРИЯ

Выбор вариантов фермента для измерения

ИИ-агенты для исследований

06

Гипотеза: выбор вариантов амилазы по прогнозу

активности и неопределённости модели выявит

больше активных вариантов, чем случайный отбор.

Данные и методы

FLIP2: измеренные варианты амилазы.

Скрываем значения активности.

Сравниваем случайный отбор,

максимум прогноза и учёт неопределённости.

Проверка на готовых данных

Бюджет: 200 раскрытых меток.

Открываем метки выбранных вариантов.

Считаем найденные варианты

из верхних 10% по активности.

Критерий: в 1,5 раза больше высокоактивных вариантов, чем при случайном отборе.

## Слайд 7

ИИ-АГЕНТЫ / БИОИНФОРМАТИКА

Память об ошибках в биоинформатических задачах

ИИ-агенты для исследований

07

Гипотеза: память с правилами обработки данных

снизит число ошибок в новых биоинформатических

скриптах по сравнению с хранением полных логов.

Задачи и методы

Обработка FASTA и таблиц генов,

объединение аннотаций и образцов.

Одна LLM: без памяти, с логами

и с обобщёнными правилами ошибок.

Проверка

Скрытые тесты: пропуски, дубликаты,

переставленные образцы и ID генов.

Равный контекст и до 3 попыток.

Раздельные задачи для памяти и теста.

Критерий: рост доли полностью корректных решений ≥10 п.п. относительно полных логов.

## Слайд 8

МАТЕМАТИЧЕСКАЯ БИОЛОГИЯ / ИДЕНТИФИКАЦИЯ СИСТЕМ

Моделирование динамики микробных сообществ

ИИ-агенты для исследований

08

Гипотеза: модель с межвидовыми взаимодействиями

точнее предскажет рост двух видов при новых

начальных пропорциях, чем независимый рост видов.

Данные и модели

Venturelli et al.: временные ряды

монокультур и пар видов.

Независимый логистический рост

и модель Лотки–Вольтерры.

Проверка переноса

Обучение: монокультуры и смесь 1:1.

Тест: смеси 95:5 и 5:95.

Ошибка прогноза численности

и итоговое соотношение видов.

Критерий: снижение ошибки прогноза ≥20% на отложенных начальных пропорциях.

## Слайд 9

ML / ФИЗИОЛОГИЯ

Персонализация прогноза глюкозы

ИИ-агенты для исследований

09

Гипотеза: поправка по первым двум дням наблюдений

снизит ошибку прогноза гликемического ответа

по сравнению с общей моделью.

Данные и модель

CGMacros: глюкоза и состав еды.

Общая модель обучается

на других участниках.

Поправка — средняя ошибка модели

на данных этого человека.

Проверка персонализации

Первые 2 дня — расчёт поправки.

Следующие дни — тест.

Прогноз: площадь под кривой

прироста глюкозы за 2 часа после еды.

Критерий: медианная ошибка по участникам снизится не менее чем на 10%.

## Слайд 10

ML / ХЕМОИНФОРМАТИКА

Оценка надёжности прогнозов для молекул

ИИ-агенты для исследований

10

Гипотеза: расхождение прогнозов нескольких моделей

лучше выявит ошибки на новых молекулярных каркасах,

чем уверенность одной модели.

Данные и методы

BBBP: проникновение веществ

через гематоэнцефалический барьер.

Признаки структуры из RDKit;

одна модель и ансамбль из пяти.

Проверка на новых структурах

В тесте — новые каркасы молекул.

Каждый метод оставляет 80% прогнозов.

Сравниваем долю ошибок

и долю ответов для каждого класса.

Критерий: меньше ошибок среди 80% прогнозов, выбранных по согласованности моделей.
